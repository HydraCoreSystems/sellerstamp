# Layout proof, November 7, 2026

These are renders of the real app code at 390 by 844 in a web view. No Android device or emulator is available in the build workspace, so the Android navigation bar (48 px, black strip) and the on screen keyboard (300 px, gray block) are drawn on top as stand ins, and the keyboard open event is fed to the app the way Android sends it. They show the layout logic, not a photo of a phone.

- a-your-stamp-bottom-bar.png: the free stamps line and the gold button sit fully above the navigation bar.
- a2-your-stamp-style-section.png: the Style heading and the first row of tiles, with the Wax Seal and Bottom band labels fully visible.
- b-keyboard-studio-field.png: the Your own main line field, focused, fully visible above the keyboard.
- b2-keyboard-settings-last-field.png: the last Settings field, focused, fully visible above the keyboard.
